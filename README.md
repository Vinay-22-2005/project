# Predicting Hospital Stay Length using Explainable Machine Learning

## 📌 Description
This project predicts the length of hospital stay for patients using machine learning models. It also uses explainable AI techniques to understand how different features affect predictions.

## 🧠 Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas, NumPy
- Matplotlib / Seaborn
- SHAP / LIME (for explainability)

## ⚙️ How to Run
1. Open the notebook file
2. Install required libraries:
   pip install pandas numpy scikit-learn matplotlib shap lime
3. Run all cells

## 📊 Features Used
- Age
- Gender
- Diagnosis
- Admission type
- Medical history

## 📈 Output
- Predicted hospital stay duration
- Feature importance using SHAP/LIME
- Graphs and visualizations

## 🎯 Conclusion
The model helps hospitals estimate patient stay duration and improve resource planning.
